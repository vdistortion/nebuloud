# Аудит slug Nebuloud

## Статус

Slug-миграция выполнена в production Directus. Автоматически переименовано:

```text
311 записей
```

Повторный dry-run `scripts/normalize-directus-slugs.py` после миграции показывает:

```text
changes: 0
```

## Применённая политика

- русский — ГОСТ Р 7.0.34-2014;
- украинский — ДСТУ 9112:2021, система Б;
- немецкий — практическое правило `ä→ae`, `ö→oe`, `ü→ue`, `ß→ss`;
- lowercase ASCII;
- слова разделяются дефисами;
- существующий slug не пересчитывается автоматически при изменении названия;
- одинаковые slug допустимы у разных артистов, поскольку артист входит в URL.

## Исключение

У артиста «Шмели» две разные песни «Бісов кут». Обе оставлены без изменений:

```text
ID 168, альбом 2021 → bisov-kut
ID 487, альбом 2009 → bisov-kut-ula
```

Их можно переименовать отдельно позднее, но сейчас это не требуется.

## Дальнейшее правило

Для новых записей slug должен генерироваться автоматически в Directus только при
пустом поле. Ручное значение нельзя перезаписывать. При коллизии внутри одного
артиста нужно добавлять уточнение, например год или тип релиза.
